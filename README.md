# AI Agent Battle — Tic-Tac-Toe

B.Tech 5th Semester AI/ML Laboratory Assignment.

## Overview
A Python Tic-Tac-Toe engine and two named AI agents compete using Minimax, Alpha-Beta pruning, configurable search depth, and heuristic evaluation. The program records node counts, pruned branches, moves, winners, and elapsed time in CSV files.

## Agents
- **NEXUS** — depth 3, Minimax + Alpha-Beta, threat-focused heuristic H1.
- **TITAN** — depth 3, Minimax + Alpha-Beta, positional heuristic H2 (threats plus center/corner control).

Both agents use deterministic algorithmic evaluation. Random selection is used only to break exact score ties.

## Heuristics
H1 scores open two-in-a-row lines strongly and one-in-a-row lines lightly, from the current agent's perspective. H2 uses similar threat scoring and adds center and corner occupancy. Terminal wins/losses receive dominant scores.

## Requirements
Python 3.9+; standard library only. No external AI or Tic-Tac-Toe library is used.

## Run
From this directory:
```bash
python main.py depth
python main.py battle
python main.py play
```
`depth` writes `results/depth_experiment.csv` and `battle` writes `results/results.csv`. The depth study holds H1 constant and compares depths 1–4 over 20 alternating-start games per depth. The battle runs 10 games with NEXUS/TITAN alternating as first player.

## Results and report
The CSV files are generated by running the code; results are not hard-coded. See `REPORT.md` for the recorded run and interpretation. Runtime measurements depend on the computer and execution environment. Re-run the commands to regenerate results on your system.

## File structure
- `game.py` — board, legal moves, win/draw detection.
- `heuristic.py` — H1 and H2 evaluation.
- `minimax.py` — Minimax, Alpha-Beta pruning, node/prune counters.
- `agents.py` — configurable Agent class and move selection.
- `experiment.py` — depth experiment, 10-game tournament, CSV output.
- `main.py` — command-line interface.
- `results/` — generated CSV results.
- `REPORT.md` — short experiment report.
